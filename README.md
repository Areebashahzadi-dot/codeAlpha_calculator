# Blush — Cute & Colorful Calculator

A responsive CodeAlpha Task 2 calculator built with HTML, CSS, and vanilla JavaScript.

## Features
- Addition, subtraction, multiplication, division and percentage
- Decimal input, all-clear and delete
- Live result preview while typing
- Keyboard support: digits, `+`, `-`, `*`, `/`, `%`, `Enter`, `Backspace`, `Escape`
- Responsive pastel interface and animated button feedback
- Safe expression parser (does not use `eval`)
- Accessible labels and reduced-motion support

## Run
Extract the ZIP and open `index.html` in a modern browser. Google Fonts need internet; the calculator works without it.

## Keyboard
`0–9` and `.` enter numbers; `+ - * /` perform operations; `%` converts the last entered number to a percentage; `Enter` calculates; `Backspace` deletes; `Escape` clears.
